# Weight Crossing

A cozy, island-style weight tracker built with **Ionic + Vue 3 + Capacitor + SCSS**, ready to ship to Android and iOS.

- Log weigh-ins in **kg, lb or stone** (stone is entered and shown as `st` + `lb`)
- Add an optional **note** to each weigh-in; tap a journal entry to edit its note, swipe left to remove
- Goal tracking, a progress chart and Pip the frog cheering you on
- Data is stored on the device with `@capacitor/preferences` (localStorage on the web)

## Requirements

- **Node 20+** (the project pins `22.12.0` in `.nvmrc`; run `nvm use 22.12.0`)
- Android: [Android Studio](https://developer.android.com/studio) (includes the SDK and JDK)
- iOS: a Mac with Xcode

## Commands

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Run in the browser at http://localhost:5173 |
| `npm run build` | Type-check and build the web app into `dist/` |
| `npm run sync` | Build and copy the web app into the native projects |
| `npm run android` | Sync and open the Android project in Android Studio |
| `npm run ios` | Sync and open the iOS project in Xcode (Mac only) |

The `ios/` project is not created yet. On a Mac, run once:

```sh
npx cap add ios
```

## Project layout

```
src/
  main.ts                 App bootstrap (Ionic, fonts, status bar)
  views/HomePage.vue      The single screen; wires everything together and Pip's messages
  components/             CozyCard, PipDialogue, StatsCard, LogCard, WeightInput,
                          WeightValue, ProgressChart, JournalList
  composables/useWeights  State + persistence (Capacitor Preferences)
  utils/units.ts          kg / lb / stone conversion and formatting
  theme/_tokens.scss      Palette, fonts and mixins (auto-injected into every component)
  theme/global.scss       Ionic colour variables and cozy alert styling
android/                  Native Android project (generated by Capacitor)
```

Weights are always stored in kilograms, so switching units never loses precision.
